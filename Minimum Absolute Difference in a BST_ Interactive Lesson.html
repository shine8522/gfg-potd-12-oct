Minimum Absolute Difference in a BST

Discover both solutions by reasoning, not memorizing. · ShineExplains

1 · Understand the problem

“Given the root of a Binary Search Tree (BST) and an integer K, find the minimum absolute difference between K and the value of any node in the BST.”

In simple words: find the node whose value is nearest to K, then report how far away it is. We need the minimum of abs(K - node->data). Here K = 13, and 13 is not in the tree.

⚠ The answer is the difference (1), not the node value (12).

4 · Was visiting every node really necessary?

We visited every node. But what did the interviewer already give us? Binary Search Tree.

Left subtree: 2, 5, 7 (all smaller than 10)

Right subtree: 12, 15, 20 (all greater than 10)

This holds at every node, not just the root: 2 < 5 < 7 and 12 < 15 < 20.

Can this help us skip unnecessary nodes? Take a moment to think.

5 · Discover the optimized approach

Observation 1. Current node = 10, target = 13. |13 − 10| = 3, so the minimum is 3. Which subtree should we explore next?
Pick one.
Observation 2. At 15: |13 − 15| = 2, so the minimum drops from 3 to 2. Left holds 12, right holds 20. Since 13 < 15 < x for every x on the right, x − 13 > 15 − 13. The right subtree cannot help, so we move left.
Observation 3. At 12: |13 − 12| = 1, so the minimum becomes 1. Since 13 > 12 we would go right, but 12 has no right child, so the search ends. Answer = 1.
Observation 4 (hypothetical, not our tree). If a node held exactly 13, then |13 − 13| = 0, the smallest possible difference, so nothing can beat it.
